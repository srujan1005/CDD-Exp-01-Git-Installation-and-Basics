# CDD Lab Experiment 1: Installation and Configuration of Git

## Objective
Install and configure Git. Create a local repository and perform basic Git operations.

## Duration
2 Hours

## Tasks
1. Install Git on your system.
2. Configure global username and email.
3. Create a new local repository.
4. Perform basic operations: `git status`, `git add`, `git commit`, `git log`.
5. Create a `.gitignore` file.

## Commands Reference
```bash
git --version
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
git init
git status
git add .
git commit -m "Initial commit"
git log
```

## Expected Outcome
A local Git repository with at least one commit.
